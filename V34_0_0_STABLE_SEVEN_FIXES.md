# V34.0.0 Stable Seven-Fix Release

Based strictly on the stable V33.9.1 project. Existing homepage, workspace, navigation, pricing, account and settings layouts were not redesigned.

1. Unified ZIP/RAR/7Z/TAR/GZ/TGZ extraction flow.
2. RAR extraction now tries rarfile and then installed 7-Zip, WinRAR, UnRAR or Windows tar.
3. Auto-fit column width and row height default to enabled.
4. Bilingual layout labels use global Source/Target terminology.
5. PLC/HMI label handling is shown only for spreadsheet work and remains inside advanced settings.
6. Existing complete Windows runtime is preserved for fast startup; no runtime folders were removed.
7. Archive errors use customer-facing Chinese messages and damaged archives are blocked before order creation.

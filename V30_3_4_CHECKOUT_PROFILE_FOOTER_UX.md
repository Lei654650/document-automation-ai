# V30.3.4 Checkout, Profile and Footer UX

- Checkout no longer asks signed-in users to enter name and email twice.
- Account details are displayed read-only during checkout and edited under Settings → Profile.
- Registration/login profile is persisted as the shared profile source for billing, orders, licenses and teams.
- Pricing comparison is collapsed by default and preceded by concise plan highlight cards.
- Footer upgraded to a six-column enterprise information architecture with language and capability areas.
- Unverified certification badges and customer-count claims are intentionally excluded.

# V32.4.0 Identity Center UI Rebuild

- Added a scalable identity-provider panel for Google and future Microsoft, Apple, and GitHub providers.
- Added Terms of Service and Privacy Policy acknowledgement text.
- Email accounts receive a safe default display name derived from the email address; profile completion can happen after sign-in.
